# Homework 3

This repository contains my solution for Homework 3.

## Contents

- `notebook/Xie_Yiling_HW3.ipynb`: Homework notebook
- `data/AReM/`: AReM activity recognition dataset
- `requirements.txt`: Required Python libraries

## Requirements

Install the required libraries with:

```bash
pip install -r requirements.txt
```

## Running the Notebook

Open the notebook from the `notebook` directory and run all cells in order. The notebook uses the following relative path to access the dataset:

```text
../data/AReM
```

## Topics

- Train and test data preparation
- Time-domain feature extraction
- Bootstrap confidence intervals
- Linear regression exercises
